# metar-explorer

A beginner Python project for retrieving and displaying aviation
weather reports and calculating runway wind components.

## Features
- Retrieves METAR data from NOAA
- Displays aviation weather information
- Calculates crosswind and headwind components
- Converts temperatures from Celsius to Fahrenheit
- Includes an offline demo and automated tests

## Run
python3 metar_tool.py RJOO --runway 18 --demo
